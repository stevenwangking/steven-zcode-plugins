# steven-zcode-plugins

文王实验室 · Steven 的 ZCode 插件市场源。仓库根目录即市场清单（`marketplace.json`），在 ZCode 中添加本仓库即可安装其中插件。

## 插件列表

| 插件 | 说明 |
| --- | --- |
| [topic-titler](plugins/topic-titler/) | 话题自动命名：首条消息提交后立即生成初版 emoji 标题，每轮结束后用独立快模型精炼稳定（类别 emoji + 对象｜目标），不打断对话 |

## 安装

1. ZCode 桌面端 → 设置 → 插件管理 → 发现 → 点 **+** 添加插件市场
2. 填入 `stevenwangking/steven-zcode-plugins`
3. 在该市场下找到插件，点 **安装**，重启一个新话题即可使用

各插件的详细用法见其目录内 README。
